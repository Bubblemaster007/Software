# 工程工作空间重构（2026-11-22）

依据用户本次任务书；新版“选中图形视图”优先于旧版默认多图堆叠。保留 Vue、ECharts、FastAPI 与离线启动方式。

## 审查结论与迁移约束

- App.vue 同时管理工程、源荷、场景引用、平衡 API、导航、菜单与全局样式。保存使用版本乐观锁，切换工程先保存；历史档案读取不得覆盖工程输入。
- DataWorkspace 的源荷与 NetworkEditor 的网络使用工程状态；EngineeringWorkspace 台账另有版本与保存 API，不能合并成一次工程保存。
- SourceStudy、SourceAnalysis、ScenarioWorkspace、SequenceWorkspace 分别调用源荷研究、事件窗口、故障生成与嵌入接口，生成与应用必须继续区分。
- aggregate/case33 共用 /api/balance；逐设备、年度、承灾、恢复、投资使用 study-jobs；随机平衡以已存源任务为基准；native-jobs 是独立后端队列，不能冒充 study-jobs。
- ConfigOverview 复用 InvestmentWorkspace 的真实任务上下文；策略复算保留 baseline_run_id。报告读取档案并进行可比性校核，质效、交付及模块交接保留各自接口。
- StudyTasks 已支持取消、冻结输入重试与完整快照；原生队列的日志和文件仍由 NativePipeline 管理。后台任务不依赖页面存活。
- 离网稳定的动态方程、权重、验证资料未交付，继续显示真实待接入状态。历史数据真实性与重建来源说明保留。
- 原平衡三页重复导航、中文命令分支、多个 App 样式块及底部保存按钮需清理。右侧/底部面板状态必须独立于业务输入。
- 详尽事件与接口清单见《工作空间重构代码审查.md》，保存了迁移前每个 Vue 组件实际事件与数据契约。
