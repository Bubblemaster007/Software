更新日期：2026年11月20日
本版替代旧11个左侧一级菜单；旧业务名称保留为内部兼容映射。
层级：业务阶段 → 二级入口 → 页内标签/步骤 → 操作按钮。专项与系统为可折叠支持组。

  └─电网建模 → 页内：电网拓扑、变压器与开关、二次设备与通信
  └─资源与负荷 → 页内：电源台账、储能台账、负荷与保供目标
  └─参数设置 → 页内：源储参数、经济参数
  └─数据校验 → 页内：数据版本管理

场景生成
  └─场景设置 → 页内：典型场景库、分类目标与优先级
  └─源荷与故障场景 → 页内：近中远期全年背景、源荷增长与极端窗口、故障与恢复场景
  └─生成与应用 → 页内：生产序列嵌入

平衡分析
  └─分析设置 → 页内：模型与资源、运行阶段
  └─计算任务 → 页内：计算任务
  └─分析结果 → 页内：平衡结果、网络逐时结果

保供优化

  └─源储协同配置 → 页内：候选资源、目标与约束、规划阶段、一二次协同规划、灵活组网、配置结果

成果管理
  └─计算档案 → 页内：计算档案
  └─方案对比 → 页内：方案对比、配置方案、质效评价

系统管理
  └─计算任务中心 → 页内：计算任务
  └─功能规划与验收 → 页内：功能规划与验收
  └─接口与交接 → 页内：接入清单、算法接口、交接任务

导航规则：只展开当前业务阶段的二级入口。专项研究与系统管理默认收起，点击展开；选择具体业务后显示其页内功能。数据页标签仅属于当前二级入口。顶部显示当前工程、业务路径、输入小时数、格式校验及工程版本。状态来自实际输入与结果存在情况，不代表全部科研验收状态。
平衡分析：分析设置显示时序、模型资源与运行阶段；计算任务仅显示所选计算模式；分析结果按模式查看。汇总/网络计算的输入、提交和结果已分开。逐设备、随机、年度和原生模式保留原组件及其任务/结果区，在计算任务和分析结果视图中复用；组件内部输入与结果尚未全部细拆。切换视图不提交计算，不应用场景。
工程首页：准备状态、核心业务流程及最近平衡结果；工程信息改为详情折叠卡片。
数据校验：显示源荷格式、网络来源、工程版本和版本管理，提供继续到场景设置入口；逐设备完整性仍由对应计算模式核验。
场景生成：背景序列、极端窗口、故障与恢复按页内标签组织；常规/极端工况目前为配置引导，未新增后端工况字段，不更改已有场景。典型模板和保供目标仍沿用原组件。
结果边界：各模式结果不得互相冒充。常规/极端结果自动分账、跨模式统一结果适配、六项概率指标统一面板以及按模式统一检索档案尚待后端与组件进一步接续；现有结果和导出入口保留。
专项研究保留真实状态；课题3动态方程、权重及验证数据未交付，仍待接入。
源码依据：navigation.ts的workflowNavigation定义左侧层级；App.vue维护旧业务映射与页内视图。不改变任务标识和后端协议。

页面布局补充：固定顶部工程操作与底部工程草稿/继续入口；侧栏可收窄。平衡设置引用当前输入并跳转数据接入编辑，分析结果中的阶段/逐时/网络详情按标签显示。首页五流程卡片提供继续入口及真实输入/档案待办。工程草稿保存不替代台账、场景和任务组件各自保存。详细抽屉及跨模式结果路由仍待进一步改造。

MATLAB式布局第一阶段：数据接入默认源荷时序，编辑器显式开启/关闭；网络默认拓扑浏览；平衡资源/阶段、指标、明细默认关闭，通过工作区工具进入。支持图形展示及恢复布局。其他业务仍沿用现有组件，统一停靠与主图解耦尚未全面完成。
