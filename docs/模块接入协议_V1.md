# 模块接入协议 1.0

工程统一单位：功率kW，电量kWh，电压pu，频率Hz，时间h，金额元。原始草稿里的百分数、分钟、万元字段仍保留字段名和单位，适配器必须显式转换，不可直接套用统一单位。

## 已提供接口

- `GET /api/integration/modules`：承灾极限、离网稳定、黑启动、一二次协同规划的输入输出约定及适配器状态。
- `GET /api/integration/topic2`：课题2实际接入清单与方法边界。
- `GET /api/integration/schema`：请求和结果的JSON Schema，契约版本1.0。
- `POST /api/integration/requests`：提交module、project_id、project_revision、可选source_run_id、scenario_id及parameters。工程版本不匹配返回409；跨工程引用或基准与场景不一致返回422。
- `GET /api/integration/requests?project_id=...`：本工程交接档案。
- `GET /api/integration/requests/{id}`：完整冻结输入、摘要和结果。
- `POST /api/integration/requests/{id}/execute`：调用已注册的Python适配器。尚未注册时返回409，不生成结果。
- `POST /api/integration/requests/{id}/result`：保存外部计算结果，必须匹配request_sha256、契约版本，并提供算法版本、状态、结论、metrics、checks和payload。外部导入标注为未独立验证。已有结果禁止覆盖，应新建任务保存新版本。

交接输入包含：归档时工程及版本、基准平衡输入和完整结果、关联场景、模块参数草稿、模型拓扑、显式参数及单位。工程当前输入与历史基准可以不同，适配器必须说明使用哪份依据。JSON采用排序键序列化后以SHA256标识输入。

## Python适配器

在应用启动时导入适配器并注册，禁止由网页上传任意可执行代码：

```python
from backend.module_contracts import register_adapter

def run(snapshot, request_sha256):
    # 读取snapshot['baseline_run']或snapshot['project']['state']，显式选择依据。
    # 在这里调用真实算法，返回如下字段；不得用示例常数充当判别结论。
    return {
        'contract_version': '1.0',
        'request_sha256': request_sha256,
        'algorithm_version': 'your-algorithm.1',
        'status': 'failed',
        'summary': '在此填写真实计算状态和原因',
        'metrics': {},
        'checks': [{'name':'电压稳定','status':'not_checked','evidence':'缺少动态模型'}],
        'payload': {},
    }

register_adapter('island_stability', 'your-algorithm.1', run)
```

支持的module：disaster_limit、island_stability、black_start、joint_planning。checks状态为passed、failed或not_checked。节点、线路、设备编号应引用快照内ID，payload应保存结果序列、约束证据、未校核项及适配器所用模型版本。注册函数的算法版本与返回版本必须一致。

## 本轮验证与未完成项

自动测试覆盖输入摘要、工程快照隔离、跨工程拒绝、版本冲突、无适配器拒绝、测试适配器调用与结果不可覆盖。测试适配器仅用于验证调用协议，没有真实物理判别能力，测试结束即移除。

当前执行接口为同步协议，正式长耗时算法还需后台任务、取消和进度机制；此接口不意味着课题1/3算法已完成。地理资产、逐设备储能、移动资源和二次系统统一底账仍待完善，当前快照只传递工程中实际已有的数据。
