## 1. 规划目标与边界

形成可离线运行、支持示范区实证的源储协同配置工具，覆盖四个课题的全部软件业务：基础数据和分类保供目标、典型场景、承灾极限、随机生产模拟与分阶段电力电量平衡、源网荷储策略、多阶段源储优化、一二次协同规划、离网稳定快速判别、黑启动恢复以及经济—安全质效评价。

本规划中的“目标功能”均为最终交付要求；“当前状态”截至编制日，必须随代码、测试和实际模型交付更新。代码入口、参数草稿和接口就绪不等于真实物理算法或项目指标通过。功能实现、科研模型精度与实证验收分别管理。用户于2026-10-31确认课题3动态方程、训练权重和时域验证数据“目前没有，先空着”；相关菜单、接口与原需求保留待交付，不生成替代模型或达标结论。

保留现有11个一级菜单，补齐二级入口，不以大幅改名打断现有操作流程。承灾极限量化统一显示为“承灾极限分析”，离网运行能力统一归入“离网稳定判别”。运行阶段指一次灾害内的资源/故障演化，规划阶段指跨建设年份的资产形成，两者采用不同对象与时钟。

## 4. 当前软件基线与关键缺口

已有：多工程版本及县域/乡镇/村三级工程类型、逐设备台账与历史版本、1/5/15/30/60分钟多节点MILP调度及构网分区逻辑、11类场景及区域目标模板、PPT需求指数和优先级计算、熵权-CRITIC-TOPSIS评价、完整需求追踪页面、CSV编辑、阿拉山口典型日转换、自定义辐射网编辑与故障、汇总/网络平衡、交流网损和稳态电压复核、资源故障场景、事件嵌入、条件随机样本、八策略建议、固定资源复算、简化枚举、档案报告与数据库备份。

现有限制：旧交互网2—100节点、2—168小时，仍为根节点供电与集中资源。新增逐设备入口支持1/5/15/30/60分钟、最长168小时，多节点源储、逐负荷目标和具备构网条件的电气失联分区；采用无损LinDistFlow，尚未贯通交流网损/动态稳定。线路状态可显式断开与恢复，暂不自动优化重构。普通汇总输入2—8760小时；原生年度网络任务固定IEEE33，未与自定义示范网络贯通。随机交互当前2—20样本。已可保存逐负荷分类目标，但旧平衡仍采用总负荷比例；台账已进入独立逐设备MILP入口，旧模型不自动替换；目标缺额分层最小化并输出时长与中断判定，可显式强制台账连续中断预算；负荷移峰/转移、前史及动态启动仍待补。承灾已接入条件随机故障扫描、Wilson/经验判定和同随机冲击设备对照，仍缺地区校准、加权场景与动态联合验证；黑启动已接工程操作束搜索、全时域硬指令复算、分区/时间/拓扑回放；仍未动态认证，离网以草稿/接口为主。固定块与有界连续容量混合、储能独立P/E、加权联合机会约束、跨期投运/退役与现金流已实现；厂家可行域、自适应投资树、一二次协同、自动质效指标、地理和真实台账缺口仍单列。

## 7. 各课题技术路线与实现要求

### 7.1 课题1：场景、分类目标与承灾极限

县域/乡镇/村与区域/季节/灾害等级建立场景模板。PPT的11类由西部县域20/50年2类、三区乡镇20/50年6类、三区村级20年3类组成；概率和灾害强度从地区资料配置。

负荷综合特性CTI按研究成果的刚性、可中断、可削减定义及权重计算，PPT分界为CTI≥0.75基本保障、0.30≤CTI<0.75居民、CTI<0.30一般。原始指标计算规则和权重未提供时，可录入已评审CTI并标注来源，不能擅造公式复现声明。

PPT第17页需求公式：Dk=w1*Ck+w2*(1-Rk/Tmax)+w3*(Tdis/Tref)+w4*(1-Sk/Smax)+w5*(1-IIk)+w6*(1-CIk)。必须逐项显示并保存原公式语义，尤其修复时长项的方向若调整需另立方法版本，不静默改写。第18页Pk=β*Dk+(1-β)*Ik，β示例0.6，Ik示例基本保障0.93/居民0.70/一般0.56。模板目标按第19页区域差异填写，最终经示范区确认。

灾害强度/时长扫描经脆弱性映射资源故障，调用平衡与保供目标判定；对单调边界可用分段/二分提高效率，非单调时保留所有可行区间。边界仅在已验证范围声明，采用置信下界或经批准的风险判据。薄弱设备用统一随机种子的控制实验量化边际失供，输出整改优先级和目标差距。

### 7.2 课题2：随机平衡、策略与动态优化

保留现有经验方法为明确标记的研究基线，接入VMD、Res-GRU、WGAN-GP、多尺度融合与概率拟合时逐环节交付模型和验证，不以名称替换算法。风险生成器需保存冻结权重、候选库和协议，时空相关性、尾部以及极端事件覆盖均须检验。

全年模型先抽样事件类型、月份与风险，再匹配极端工况、迁移异常增量并进行风险保持的边界平滑；同时携带设备可用状态与资源能力。正常/极端及灾前/冲击/持续修复/恢复统计分开，概率类按有权重样本计算，单轨迹时段比例单独命名。

调度层采用可验证LP/MILP或研究算法，约束逐设备功率、能量、启停、燃料、爬坡、负荷调节、根供及孤岛平衡、线路/变压器容量和电压。规划层将源储选址容量和跨期建设作为先验决策，场景应急调度作为后验决策，加入投资预算和机会约束；采用SAA及MILP或实际交付的改进逐步对冲，记录可行解、下界、gap和样本外效果。

### 7.3 课题3：离网判稳、恢复及一二次规划

离网模型输入含PCC工况、网络、短路比、等效惯量、源荷扰动及控制方式。训练样本以时域仿真为真值，冻结训练/验证/测试分组；归一化、神经网络权重和适用域绑定版本。预测最大频率偏差、RoCoF、最低电压及恢复时间，结合关键变流器限幅死区、限流优先级的光滑化机理约束；稳定边界按交付的广义李雅普诺夫/BCU模型验证，控制优化后重新判稳。没有样本或机理模型时，只提供明确标识的基础筛查或未校核结果，不宣称复现PPT神经网络与能量边界。

黑启动先评估水电、构网储能和风光组合的自启动/建压能力，再按负荷重要度排序、容量和电气距离匹配扩展分区。支持串行与并行恢复，合区执行电压幅值/相角/频率预同步校验。MRSCR必须使用明确的研究公式与可追溯短路参数，不能直接拿普通SCR替代；PPT第43页分级阈值仅作可配置研究规则。每一步校验能量、容量、过载、电压频率、励磁涌流、开关布点、自动化终端、通信路由及操作前置关系。优化目标兼顾恢复时间、优先负荷和风险，失败步骤明确原因和备选路径。

一二次规划同时建模变电站/线路/开关，以及协调控制器、执行终端和通信链路部署，评估故障下控制可达性、分区自治与灵活组网；与源储及黑启动计算共享节点和设备ID。300节点性能试验必须包含实际二次约束，不能只对普通网络最短路计时。

### 7.4 课题4：软件集成、示范与质效

统一离线数据库和模块契约。新疆阿拉山口作为当前数据接入起点，同时支持青海玉树囊谦县、福建福鼎台山岛等示范工程模板（完整PPT第52—53页的建设节点仅为2026年7月汇报信息，实证状态须另行核实），覆盖县域/村镇两类实证。建立现状、规划、建设落地、实测运行四种依据，分别记录软件预测和实证结论。

经济指标包含投资、运维、燃料、移动资源、缺供损失、净现值/年化成本；安全指标含保供目标、可靠性、稳定裕度、恢复时间及路径可行性。按完整PPT第54—57页采用极值标准化、熵权法-CRITIC组合赋权与TOPSIS贴近度排序；保存正负向、矩阵、权重与距离，补充权重敏感性与缺失值处理。组合比例在PPT未定时作为显式研究假设，不声称复现未公开参数。指标体系按第55页包含N-1通过率、综合供电可靠率、多时间尺度失负荷比、孤网稳定运行时长、电压和频率稳定裕度、黑启动总恢复时间、投资回报期、收益成本比、极端事件期望损失。硬安全指标失败时方案不可推荐，未动态校核的方案不能得到“全面安全”结论。

## 16. 端到端业务验收脚本规划

1. 阿拉山口数据闭环：导入原始资料并确认单位 → 编辑线路、节点和逐设备台账 → 设置线路/设备故障及修复 → 冻结版本 → 调度 → 核对CSV、曲线及输入来源 → 修改现状后重开旧结果，验证快照不变。
2. 分类保供闭环：选择县域/乡镇/村与地区模板 → 确认负荷分类、目标功率和时长 → 生成场景 → 运行分阶段调度 → 核对基本保障/居民/一般目标、主动削减与缺供 → 时域不足项显示未校核。
3. 承灾与策略闭环：设定强度/时长、概率来源、样本和种子 → 批量扫描并记录任务状态 → 形成已测边界与置信度 → 同条件薄弱设备对照 → 八策略选用及资源调整 → 重新计算实际改善。
4. 规划与恢复闭环：候选源储和建设年份 → 多场景选址定容 → 样本外调度 → 离网稳定判别及控制反馈 → 串并行黑启动、预同步与通信校核 → 失败项返回规划修订，不将未校核判为通过。
5. 评价与交付闭环：选取可比方案 → 汇总经济安全原始指标 → 熵权-CRITIC/TOPSIS及敏感性 → 独立安全门槛 → 示范实测对比 → 报告、离线安装、备份恢复和性能精度证据归档。

上述为待实施验收脚本规划；第13节既有测试只能证明对应已实现范围。每轮交付应在《软件开发进展.txt》同步登记需求ID、变更范围、实际验证及未完成项，并同步维护本规划与机器可读清单。
