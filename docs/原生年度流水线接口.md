# 原生年度流水线接口

菜单：“电力电量平衡 → 原生年度流水线”。

该入口调用未修改的`src/chapter3/current_paper_adapter.run_paper_downstream`，连接年度资源与支路连续故障、IEEE33线性调度、交流网损迭代、事件条件样本与分阶段统计、策略触发及简化规划。SC-RCRB生成和认证不在该入口执行。

## CSV格式

必需列：timestamp、load_kw、wind_kw、pv_kw、event_id、wind_speed。2至8760小时，时间连续逐小时、功率非负有限、风速0至100m/s。event_id=-1为事件外；每个非负事件ID必须占据连续36小时，采用原代码6/6/12/12小时测试分段。

可选列：

- random_sequence_id：单任务仅一条轨迹，编号非空且一致。
- sequence_weight：单任务权重须为1，不在此入口合并多条轨迹。
- available_kw_{grid_channel,transformer,emergency_gen,storage,renewable}：显式逐时可用容量，0即不可用。
- failure_rate_per_hour_{同上资源类型}与repair_hours_{同上资源类型}：必须成对提供，失效率0至10/h，修复时长1至8760整数小时。未提供时不额外杜撰该资源故障。

本模型不接受汇总available_kw_line来代替具体支路故障；支路故障由原始风速条件测试公式生成，尚非校准设备脆弱性模型。输入字段无自动省略，未知字段会拒绝。

## 请求与产物

`POST /api/native-jobs`提交project_id、project_revision、csv、parameters（与平衡资源参数相同）、network_parameters、branch_limit_kw、seed、event_samples（1至20）。输入和配置在任务创建时冻结，过期工程版本被拒绝。一次仅运行一个原生任务。

任务在独立Python进程中运行，页面关闭后继续。任务记录PID及操作系统进程创建时间，查询时识别已经退出或PID复用的进程，标记interrupted，不把进程退出当作计算成功。

- `GET /api/native-jobs?project_id=...`：本工程任务清单。
- `GET /api/native-jobs/{id}`：状态和完成摘要。
- `GET /api/native-jobs/{id}/input`：冻结输入、配置与结果。
- `GET /api/native-jobs/{id}/files`：原始产物清单。
- `GET /api/native-jobs/{id}/file?path=...`：下载单个产物，路径必须位于本任务输出目录内。
- `GET /api/native-jobs/{id}/archive`：任务终止后下载完整ZIP，包含输入快照、worker日志及原始产物。

正常产物包括annual_random_production_sequence.csv、line_failures.csv、resource_failures.csv、balance/hourly_balance.csv、balance/ac_screen.csv、事件分阶段和条件样本、strategies.csv、planning.json、run_summary.json。交流校核不通过时任务失败，保留原始证据文件，不生成成功结论。

目录为data/native_jobs/{id}，数据库只存输入、配置、状态和摘要；SQLite备份不会打包外部产物，需另下载任务ZIP或备份此目录。当前无界面取消或暂停功能，也不自动续算中断任务。原生任务和交互平衡分别归档，后续需统一报表对比口径。

## 验证范围

自动测试实际调用原生36小时网络调度和2个事件条件样本，核对供电缺额积分、事件产物、ZIP和越界路径拒绝。8760小时现场验证另存docs/原生年度任务验证.json；所用数据为合成年背景、零风速占位与人为36小时事件，只验证功能接通，不构成区域实证或方法认证。
